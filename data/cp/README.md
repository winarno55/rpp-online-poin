# Folder Aset Dokumen CP (Capaian Pembelajaran)

Folder ini disediakan untuk menyimpan file PDF Resmi Capaian Pembelajaran (CP) agar AI Gemini dapat membaca dokumen asli secara presisi 100%.

## Daftar File yang Diperlukan:

1. **`cp-020-2026-pai.pdf`**
   - Khusus untuk Mata Pelajaran **PAI (Pendidikan Agama Islam dan Budi Pekerti)**.
   - Sumber: Keputusan Kepala BSKAP No. 020/H/KR/2026.

2. **`cp-046-2025-umum.pdf`**
   - Untuk **Seluruh Mata Pelajaran Umum** (selain PAI) seperti Bahasa Indonesia, Matematika, IPA, IPS, Pancasila, Inggris, dll.
   - Sumber: Keputusan Kepala BSKAP No. 046/H/KR/2025 (atau versi revisi umum terbaru).

---

## Cara Menambahkan File PDF via GitHub:

1. Salin/rename file PDF Anda dengan nama persis sesuai di atas:
   - `cp-020-2026-pai.pdf`
   - `cp-046-2025-umum.pdf`
2. Taruh/upload kedua file tersebut ke dalam folder ini (`data/cp/`).
3. Lakukan Commit dan Push ke repository GitHub Anda.
4. Sistem server akan secara otomatis mendeteksi file PDF tersebut dan mengirimkannya langsung ke AI Gemini setiap kali pengguna membuat Modul Ajar atau Alur Tujuan Pembelajaran.

---

*Catatan: Jika file PDF belum diunggah, sistem akan otomatis beralih menggunakan Google Search grounding dan database standar tanpa menimbulkan error.*
